    You’ll need a free GitHub account to post the issue. Comfortable with code? Edit data/listings.json and open a pull request instead.

    What Gets Listed

    • Civic tech: tools, apps, data portals or bots that help citizens use, watch or improve public services.
    • CSOs: non-government, non-profit groups working on a public issue in the Philippines.
    • It must be findable: a site, repository, page or registration.
    • Dormant projects stay listed and are marked dormant, so the work isn’t lost.

    What Happens Next

    • Your entry becomes a GitHub issue labelled listing.
    • A moderator checks the link and the details.
    • Once approved, it’s added to the data file and appears here with a verified date.
